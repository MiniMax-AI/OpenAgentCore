OpenAgentCore runs AI agents on your own infrastructure behind the OpenAI Agents API. The [architecture overview](https://github.com/MiniMax-AI/OpenAgentCore/blob/f6d258735fc601c521dd990e6f9e1ed261f4ef2d/docs/architecture.md) explains its parts. Pick the guides for your role.

## Operators

Operators install Core and Web, add sandbox capacity and issue Project API keys.

| Guide | Covers |
| --- | --- |
| [Install Core and Web](/install) | The default installation, from an empty host to the first Project API key |
| [Installation options](/install-options) | Installer flags, existing reverse proxies, split and native deployments, offline hosts |
| [Nodes](/hosted-providers) | Adding, changing, removing and troubleshooting sandbox nodes |
| [Operations](/troubleshooting) | The `oac` command, the Core key, backups, upgrades and troubleshooting |
| [Configuration reference](/configure) | Every setting, file and environment variable |
| [Web console](/console) | What the console shows and manages |

## Application developers

Application developers call the API with a Project API key, and can run Sessions on machines they own.

| Guide | Covers |
| --- | --- |
| [Quickstart](/quickstart) | From a Project API key to a finished Session |
| [User guide](/user-guide) | Common tasks: harness and model choice, follow-ups, capabilities, files, cancel |
| [Agents API guide](/sessions) | Every resource, with SDK and HTTP examples |
| [Self-hosted execution](/self-hosted-execution) | Running a Session on your own machine |
| [Examples](/examples) | Complete applications built on the API |
| [API index](/public-api) | All three namespaces and their credentials |
