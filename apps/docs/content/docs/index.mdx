Start with the path that matches your role. These pages are the canonical sources
for the documentation website; generated site pages are not a second manual.

## First installation and first task

1. [Install Core and Web](/install), then sign in with the Core key.
2. [Add managed execution capacity](/hosted-providers) or
   [connect your own Runtime](/self-hosted-execution).
3. Issue a Project API key and follow the [first Session walkthrough](/quickstart).
4. Continue with the [user guide](/user-guide) for capabilities, files and recovery.

## Build an application

The [user guide](/user-guide) connects common tasks to their detailed contracts.
The [API index](/public-api) identifies each caller and credential. Use the
[coverage record](https://github.com/MiniMax-AI/parsar-core/blob/e4d5a1d30520a967b3a44a257ed1b6c21e388388/contracts/agents-api/README.md) to check operation support
and Harness differences before relying on an optional feature.

## Extend Core

Start with the [developer guide](/development). It links the repository map,
required checks and extension points for Harness adapters, Runtime implementations
and Sandbox Providers. Architecture rules live in
