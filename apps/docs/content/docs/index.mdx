OpenAgentCore runs AI agents on your own infrastructure behind the OpenAI Agents
API. Pick the path that matches your role. New here? Read the
[architecture overview](https://github.com/MiniMax-AI/parsar-core/blob/f6d258735fc601c521dd990e6f9e1ed261f4ef2d/docs/architecture.md) first.

## Operators: install and run

1. [Install Core and Web](/install) and sign in.
2. Add execution capacity: [managed nodes or E2B](/hosted-providers), or
   [your own machine](/self-hosted-execution).
3. Issue a Project API key and hand it to the application developer.
