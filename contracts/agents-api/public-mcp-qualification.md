# Public Environment-origin MCP qualification

This record covers explicit public HTTP MCP declarations through the pinned
official client, Core, Runtime and native Harness adapters. The
[Environment contract](environments.md#public-mcp-connection-origin) owns the
supported origin, credential and policy semantics.

Acceptance is in progress on Linux. Results, exact source and limitations will
be recorded before merge. Earlier Plugin-only evidence does not qualify this
public entrypoint. Service-origin workspace forwarding, other Sandbox Providers,
macOS/Windows real model execution, public stdio, inline headers/metadata and
MiniMax non-null allowlists/required initialization are outside this batch.
