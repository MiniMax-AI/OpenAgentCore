02 / Get started

Install. Sign in.
Add a node.

Install Core and Web together. Add execution nodes when you need them.

Read the installation guide →
BEFORE YOU START

Use a verified Linux amd64 bundle. Choose an HTTPS address reachable from your nodes and sandboxes, and configure DNS/TLS before the first install.

Download a matching bundle from GitHub Releases, signing in if GitHub asks. For unreleased changes, build from source.

  1. 01

    Install Core + Web

    ZERO NODES

    Run from your extracted bundle. Core, Web and PostgreSQL start together. No model key required.

    ./install.sh \
    --public-url https://core.example
  2. 02

    Sign in to your console

    Open the address printed by the installer. Sign in with the Core key in this private file:

    ~/.parsar/core/secrets/core.key

    The paired console is already connected to Core.

  3. 03

    Bring a node online

    Open Nodes, choose Docker or microsandbox, then Save configuration. Select Add node, then copy and run the command on a prepared Linux host.

    Dockermicrosandbox

    Web shows when the node is online and its provider is ready. All nodes use the same provider.

Installation and enrollment do not call a model. Other installation options ↗
