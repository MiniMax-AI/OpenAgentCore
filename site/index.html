02 / Installation

Start with a
local bundle.

Download or build a bundle for your host, extract it, then run the installer from that directory.

The default runs Core, the Web console and PostgreSQL with zero execution nodes. A local sandbox provider is an explicit installation option.

Installation guide →

Core + Web

DEFAULT
./install.sh

Includes PostgreSQL. No sandbox provider, KVM or systemd user service required.

Local sandbox

Optional microsandbox. Add --provider docker to choose Docker.

./install.sh --sandbox-provider true

Core only

Deploy the API without the Web console.

./install.sh --core-only

Web only

Connect the console to an existing Core.

./install.sh --web-only

Bundle availability and supported hosts are documented in the installation guide. Browse releases ↗
